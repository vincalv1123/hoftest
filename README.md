# Hall of Fame Demo

A demo of the Sleeper Hall of Fame with two made-up 12-team leagues, switchable at the top of the menu:

- **Redraft**: ten seasons (2017–2026), a new draft every year.
- **Dynasty** (superflex): a 2017 startup draft, a rookie draft every year after, and supplemental drafts in 2020, 2023 and 2026. Rosters carry over, players age and retire, and new rookie classes arrive each year, so the dynasty draft grades (rookie, startup and supplemental drafts judged over the long run) have real history to work with.

Everything is generated in the browser from a seed, so the same link always shows the same league. "New league" (top right) makes a different one (`?seed=<number>`).
