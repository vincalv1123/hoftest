# Hall of Fame Demo

A demo of the Sleeper Hall of Fame with a made-up league: 12 teams, ten seasons (2017–2026), random players, drafts, trades, waivers and scores.
Everything is generated in the browser from a seed, so the same link always shows the same league. "New league" (top right) makes a different one (`?seed=<number>`).

The current season is mid-week, so live matchups, playoff and title odds all work.
